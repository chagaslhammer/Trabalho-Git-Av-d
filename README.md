Esse projeto é uma calculadora em Python: é um exemplo clássico de programa interativo e estruturado: ela combina funções matemáticas simples com entrada e saída de dados pelo terminal. Feita por Caio Daniel e Gabriel Freitas /chagaslhammer, Gabrielvalis


Nesse projeto, vamos apresentar um trabalhinho simples, um aplicativo de calculadora feita em python, sem um propósito muito grande, mostraremos informações mais
relevantes nos arquivos colocados na pasta e se pudermos, toda a codificação do aplicativo.
